# 프로젝트 방향과 운영 기준

## 목표와 독자

Golang All In One은 Go 언어의 문법부터 테스트, 동시성, 데이터 처리와 HTTP 서비스까지 이어지는 한국어 학습 교재입니다. 독자가 코드를 읽는 데서 그치지 않고 직접 실행하고 수정하고 오류를 설명할 수 있게 만드는 것이 목표입니다.

Go를 처음 배우는 독자를 기본으로 합니다. 다른 언어, SQL 또는 데이터 처리 경험이 있는 독자는 익숙한 개념을 빠르게 통과할 수 있도록 각 장에 목표와 사전 지식을 명시합니다. 특정 언어를 이미 안다고 가정하여 Go의 중요한 동작을 생략하지 않습니다.

## 학습 결과

기본 과정을 마친 독자는 다음 작업을 스스로 수행하는 것을 목표로 합니다. 현재 구현 완료를 뜻하는 목록은 아니며, 작성 상태는 [목차](../book/README.md)에 있습니다.

- Go 모듈과 패키지를 구분하고 프로그램을 실행·빌드·테스트한다.
- 타입, 값 복사, 포인터, 슬라이스, 맵, 인터페이스와 오류 처리를 설명한다.
- 파일, CSV, JSON을 읽고 검증하는 CLI를 만든다.
- 고루틴과 채널을 적절히 사용하고 취소·종료·동기화를 설계한다.
- HTTP API와 데이터베이스 접근 코드를 작성하고 테스트한다.
- 로그, 설정, 프로파일링과 배포의 기본을 다룬다.

## 처음 정한 설계

| 결정 | 이유 | 이후 변경 시점 |
| --- | --- | --- |
| 한국어 Markdown 본문 | GitHub에서 바로 읽고 변경 이력을 검토할 수 있음 | 웹 출판이 필요해졌을 때 원고를 재사용 |
| 루트의 단일 Go 모듈 | 한 번의 `go test ./...`로 모든 기본 예제를 검증 | 독립 프로젝트·의존성 분리가 실제로 필요할 때 |
| 예제별 디렉터리 | 여러 `main` 함수의 충돌을 피하고 실행 대상을 명확히 함 | 프로그램 구조를 배우는 장에서 패키지 분리 |
| 표준 라이브러리 우선 | 언어와 핵심 API의 동작을 먼저 이해 | 특정 문제에 외부 라이브러리가 필요한 장 |
| 문제와 해설 분리 | 답을 먼저 보지 않고 직접 생각할 기회 제공 | 같은 원칙을 유지하며 문제 유형 확장 |
| Windows·Linux CI | 두 환경에서 기본 코드와 문서를 계속 확인 | 플랫폼별 기능이 늘면 테스트 추가 |

Go 모듈·패키지의 정의와 도구의 동작은 [How to Write Go Code](https://go.dev/doc/code), [Go Modules Reference](https://go.dev/ref/mod)를 참고합니다. 위 구성은 이 교재를 위한 선택이며 모든 Go 프로젝트에 강제되는 표준 디렉터리 구조는 아닙니다.

## 버전 기준

`go.mod`에는 `go 1.27.0`을 기록하고, CI는 `1.27.x`의 최신 패치를 사용합니다. 설치 안내에서 확인한 패치는 2026-11-09 기준 **1.27.3**입니다. 버전 정보는 [공식 다운로드](https://go.dev/dl/)와 [릴리스 이력](https://go.dev/doc/devel/release)을 기준으로 갱신합니다.

`go` 지시문은 모듈의 최소 Go 버전을 나타내며 개발 도구 선택에도 영향을 줍니다. 자세한 규칙은 [Go Toolchains](https://go.dev/doc/toolchain)에서 확인합니다. 학습 환경은 기본적으로 Go 1.27 계열의 최신 패치를 사용하고, 더 높은 계열을 검증 없이 지원한다고 단정하지 않습니다.

## 장의 완료 기준

본문을 작성한 뒤에는 다음 사항을 확인합니다.

1. 학습 목표를 해당 장의 설명·예제·문제로 확인할 수 있습니다.
2. 예제를 안내된 위치에서 실행할 수 있고 실제 출력이 설명과 일치합니다.
3. 필요한 사전 지식과 새 용어를 설명했습니다.
4. 실패 사례를 정상 예제와 구분했고, 자주 생기는 오류의 원인과 해결 방법을 적었습니다.
5. 연습문제·힌트·해설을 제공하며 새 코드에는 필요한 동작 검증이 있습니다.
6. 로컬 링크와 공식 참고 자료를 확인했습니다.
7. 영향을 받는 테스트와 자동 검사가 성공했습니다. 검증하지 못한 사항은 명시했습니다.
8. 목차와 로드맵의 상태, 이전·다음 장 탐색을 갱신했습니다.

작성된 본문이라도 독자 피드백과 Go의 변화에 따라 수정합니다. 빈 제목과 템플릿만 추가한 장을 완료 상태로 처리하지 않습니다.

## 현재 범위와 다음 작업

현재 교재 구조, 집필 지침과 자동 검사를 갖추고 00–04장의 본문·실행 예제·연습문제·해설을 제공합니다. 환경 준비, 값의 계산, 조건과 반복에 이어 함수의 입력·반환·스코프·가변 인자·클로저까지 다룹니다. 다음 집필은 [목차](../book/README.md)의 05장부터 순서대로 진행합니다. 최종 프로젝트의 완성 코드와 05–31장의 본문은 집필 예정입니다.

웹사이트 출판, 강의 영상 제작과 별도 데이터베이스 실행 환경은 해당 내용이 필요해질 때 추가합니다. 라이선스는 아직 정하지 않았으며 프로젝트 소유자가 코드와 원고의 공개·재사용 범위를 결정한 뒤 파일을 추가합니다.
