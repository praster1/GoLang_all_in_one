# 집필 로드맵

이 문서는 교재가 지금 제공하는 내용과 앞으로 집필할 내용을 구분합니다. 전체 32장(00–31장)의 주제와 학습 결과는 [교재 목차](../book/README.md)를 기준으로 합니다. 아래 순서는 집필 순서이며 완료 날짜를 약속하는 일정표는 아닙니다.

## 상태의 의미

| 상태 | 의미 |
| --- | --- |
| 예정 | 주제와 목표를 정했으며 본문은 아직 없음 |
| 집필 중 | 본문 또는 실습을 작성 중이며 누락된 부분이 있음 |
| 초안 | 본문과 해당 실습 자료를 제공하며 추가 검토·개선이 가능함 |
| 검토 완료 | 내용·출처·실행·연습문제의 확인 결과를 변경 기록에 남김 |

“초안”이라는 표시는 해당 장의 모든 설명을 독립적으로 검수했다는 뜻이 아닙니다. 실제로 실행한 검사와 환경은 해당 변경의 기록을 확인합니다.

2026-11-09에 00장을 상세 집필했습니다. 운영체제별 설치, IntelliJ IDEA·GoLand·VS Code 설정, 모듈과 도구 체인 진단, 개인 실습과 해설을 포함합니다. 명령 실행 결과는 반영한 PR의 검증 기록에 남기며, 설치·IDE GUI 절차의 공식 문서 검토와 실제 명령 실행 환경을 구분합니다.

03장은 `if`·`switch`의 선택, `for`의 실행 순서와 종료 조건, 정수 `range`, `break`·`continue`, 중첩 반복을 다룹니다. 실행 예제 7개, 기본 문제 6개와 선택 FizzBuzz, 실행 가능한 풀이 4개를 제공합니다. 문자열 순회와 `fallthrough`는 선택 학습으로 구분했습니다. 분기의 경계값·0회 반복·잘못된 입력·실습 명령을 확인하고 검증 결과를 해당 PR에 기록합니다.

## 집필 단계

### 단계 1. 기초 문법을 직접 설명하고 사용할 수 있게 만들기

**범위:** 02–07장. 변수, 제어 흐름, 함수, 컬렉션, 문자열을 다룹니다. 02–03장을 제공하며, 다음 집필은 04장입니다.

각 장마다 한 번에 실행할 수 있는 작은 프로그램과 세 수준의 문제를 추가합니다. 정답을 보기 전에 결과를 예측하는 질문을 넣습니다. 슬라이스의 공유 저장 공간, 맵 조회의 존재 여부, 한글의 바이트와 룬 차이를 별도 실습으로 확인합니다.

**완료 기준:** 작은 입력 데이터를 조건·반복·함수로 처리하고, 컬렉션과 문자열에 관한 대표적인 오해를 예제로 설명할 수 있습니다.

### 단계 2. 코드 구조와 오류·테스트를 연결하기

**범위:** 08–13장. 구조체·인터페이스·패키지·오류·테스트·제네릭을 다룹니다.

동작하는 예제에 책임 분리와 오류 경로를 추가하는 방식으로 진행합니다. 인터페이스를 도입하기 전에는 실제로 바꿔 끼울 동작이 무엇인지 설명합니다. 테스트와 제네릭을 위해 불필요하게 복잡한 설계를 도입하지 않습니다.

**완료 기준:** 여러 패키지로 구성한 작은 프로그램에 명시적인 오류 처리와 의미 있는 자동 테스트를 작성할 수 있습니다.

### 단계 3. 실제 입력과 여러 작업의 수명 다루기

**범위:** 14–20장. 파일·직렬화·CLI·작업 취소·고루틴·채널·동기화를 다룹니다.

예제 데이터는 저장소에 포함한 가상 데이터나 테스트가 만든 임시 데이터를 사용합니다. 동시성 예제는 시작뿐 아니라 완료 대기·취소·종료 조건을 포함합니다. 시간 지연으로 우연히 성공하는 예제를 기본 패턴으로 제시하지 않습니다.

**완료 기준:** 입력 오류와 자원 정리를 처리하고, 제한된 수의 작업이 종료되는 동시 프로그램을 작성할 수 있습니다.

### 단계 4. HTTP API와 데이터베이스 연결하기

**범위:** 21–25장. HTTP 클라이언트·서버·API 검증·SQL·운영 기초를 다룹니다.

표준 라이브러리로 요청과 응답의 흐름을 먼저 학습합니다. 데이터베이스 드라이버 등 외부 의존성이 필요한 단계에서는 이유, 버전, 설치 방법, 테스트 범위를 기록합니다. DB 실습은 별도 개발용 환경에서 실행하도록 구성합니다.

**완료 기준:** API 계약을 테스트하고, 요청 취소와 DB 오류를 처리하며, 서버를 정리해서 종료할 수 있습니다.

### 단계 5. 측정·검사·배포와 종합 실습 완성하기

**범위:** 26–31장. 성능·퍼징·CI·빌드·세 가지 프로젝트를 다룹니다.

측정은 추정과 구분하고 환경과 명령을 기록합니다. 종합 실습은 기본 기능 → 오류 처리 → 테스트 → 개선 순서로 나눕니다. 선택 확장은 기본 기능의 완료와 구분합니다.

| 종합 실습 | 최소 완료 범위 | 선택 확장 |
| --- | --- | --- |
| CSV 분석 CLI | 파일·표준 입력, 행 검증, 집계, 오류 보고, 테스트 | 큰 파일 처리, 출력 형식 선택, 측정에 따른 최적화 |
| 할 일 HTTP API | 생성·조회·수정·삭제, 입력 검증, 저장소, 핸들러·DB 테스트 | 페이지 나누기, 인증 연동, 관측 지표 |
| 동시 배치 처리 | 작업 수 제한, 취소, 결과 수집, 오류 보고, 종료 테스트 | 재시도 정책, 속도 제한, 체크포인트 |

**완료 기준:** 세 프로젝트를 처음부터 실행할 수 있으며, 설정·제약·검사 방법·의도적인 단순화가 문서화되어 있습니다.
