# 참고 풀이

이 폴더는 연습문제를 직접 시도한 뒤 비교하는 참고 풀이입니다. 요구 사항을 만족하는 다른 구현도 정답이 될 수 있습니다. 풀이를 본 후에는 코드가 왜 그렇게 동작하는지 설명해 보세요.

## 01장: 첫 Go 프로그램

문제: [01장 연습문제](../exercises/01-first-program/README.md)

### 문제 1: 인사말 바꾸기

첫 예제의 `main` 함수 안에 다음 출력문을 둡니다.

```go
fmt.Println("Go를 공부합니다.")
```

이 코드는 전체 파일이 아니라 출력문만 제시한 조각입니다. `package main`, `import "fmt"`, `func main()`을 포함한 전체 구조는 [첫 프로그램](../examples/01-first-program/hello/main.go)을 참고합니다.

### 문제 2: 두 줄 출력하기

`main` 함수 안에 두 문장을 순서대로 둡니다.

```go
fmt.Println("Go를 공부합니다.")
fmt.Println("작은 프로그램부터 직접 실행합니다.")
```

각 호출이 줄바꿈을 붙이므로 문장 사이에 별도의 빈 출력문을 넣지 않습니다.

### 문제 3: 이름으로 인사말 만들기

- [실행 가능한 풀이](01-first-program/greeting/main.go)
- [입력별 결과를 확인하는 테스트](01-first-program/greeting/main_test.go)

저장소 루트에서 실행합니다.

```text
go run ./solutions/01-first-program/greeting
go test -v ./solutions/01-first-program/greeting
```

프로그램의 예상 출력:

```text
안녕하세요, Go!
```

풀이의 핵심은 세 단계입니다. 먼저 `strings.TrimSpace`로 앞뒤 공백을 정리합니다. 다음으로 빈 이름이면 기본 이름을 선택합니다. 마지막으로 인사말 문자열을 만들어 반환합니다. 출력은 `main`에서 수행하므로, 테스트는 입력 이름에 따라 어떤 문자열이 만들어지는지를 직접 확인할 수 있습니다.

예를 들어 `"   "`는 원래 빈 문자열이 아닙니다. 공백을 정리한 뒤에야 `""`가 됩니다. 따라서 빈 이름 검사를 공백 정리보다 먼저 수행하면 문제의 요구 사항과 다른 결과가 생길 수 있습니다.

## 풀이를 추가할 때

풀이에는 해당 문제 링크, 실행 명령, 기대하는 동작, 핵심 선택 이유를 함께 기록합니다. 테스트는 요구 사항과 경계 조건을 확인하며, 아직 제공하지 않은 문제의 풀이를 먼저 추가하지 않습니다. 자세한 작성 기준은 [집필 가이드](../docs/AUTHORING.md)를 따릅니다.
