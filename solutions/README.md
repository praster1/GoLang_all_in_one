## 해설을 추가할 때

해당 문제 링크, 실행 명령, 기대하는 동작, 핵심 선택 이유를 함께 기록합니다. 테스트는 요구 사항과 중요한 경계 조건을 확인합니다. 자세한 기준은 [집필 가이드](../docs/AUTHORING.md)를 따릅니다.
