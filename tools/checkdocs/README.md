# 문서의 로컬 링크 확인

저장소 루트에서 다음을 실행합니다.

```sh
go run ./tools/checkdocs
```

이 도구는 Markdown의 일반 인라인 링크와 이미지 링크가 가리키는 **로컬 파일·디렉터리의 존재 여부**를 확인합니다. 대상이 없으면 파일 경로와 줄 번호를 출력하고 종료 코드 1을 반환합니다. 별도 라이브러리 설치나 네트워크 접근은 필요하지 않습니다.

## 지원 범위

- `문서.md`, `../examples/`, `문서.md#제목`과 같은 상대 경로
- `%20`처럼 URL 인코딩된 경로
- 큰따옴표 제목이 있는 인라인 링크
- 백틱 또는 물결표로 감싼 코드 블록 내부의 예시 링크 제외
- 같은 길이의 백틱으로 닫힌 인라인 코드 내부의 링크 모양 제외: `first[int](nil)` 같은 제네릭 호출 포함
- 인라인 코드의 여러 백틱 구분자와 같은 문단 안의 줄바꿈 처리; 닫히지 않은 백틱 뒤의 실제 링크는 계속 검사
- `.git/`, `_practice/`, `bin/`, `dist/`, `vendor/`, `node_modules/` 제외

## 별도로 확인할 항목

웹 주소의 접속 가능 여부, `#제목` 앵커의 실제 존재, 참조형 링크, HTML의 링크는 검사하지 않습니다. 괄호가 포함된 경로나 여러 줄에 걸친 링크, 복잡한 목록·인용문의 블록 경계 등 Markdown의 모든 문법을 처리하는 파서는 아닙니다. 인라인 코드 구분자는 [CommonMark 코드 스팬 규칙](https://spec.commonmark.org/0.31.2/#code-spans)을 따르되, 문단은 빈 줄과 코드 블록을 경계로 구분합니다. 이 저장소에서는 단순한 상대 경로 인라인 링크를 기본으로 사용합니다.

본문의 Go 코드와 실행 결과가 일치하는지는 예제 테스트와 실제 실행으로 확인합니다. 링크 검사가 성공했다는 사실만으로 본문 전체가 검증되었다고 판단하지 않습니다.
