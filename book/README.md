# Go 학습 교재 목차

Go를 처음 배우는 독자가 작은 프로그램을 직접 실행하면서 HTTP API와 데이터 처리 프로그램까지 만들어 가는 한국어 교재입니다. 설명을 읽은 뒤에는 예제를 실행하고, 출력을 바꿔 보고, 연습문제를 풀어 이해를 확인합니다.

**현재 공개된 본문은 00–02장입니다.** 그 뒤의 항목은 집필 계획이며, 아직 존재하지 않는 장으로 연결하지 않습니다. 전체 진행 상태와 집필 순서는 [로드맵](../docs/ROADMAP.md)에서 확인합니다.

## 읽는 방법

1. 처음 시작한다면 00장에서 개발 환경을 확인하고, 01장에서 첫 프로그램을 실행합니다.
2. 각 장의 **학습 목표 → 개념 → 예제 실행 → 코드 설명 → 연습문제 → 요약** 순서로 읽습니다.
3. 예제 명령은 별도 표시가 없는 한 저장소 루트에서 실행합니다.
4. 문제를 먼저 풀고 힌트를 확인합니다. 해설 코드는 자신의 풀이와 결과를 비교할 때 엽니다.
5. 기존 프로그래밍 경험이 있다면 기초 설명을 빠르게 읽되, 슬라이스·인터페이스·오류 처리·동시성의 Go 방식은 직접 실습합니다.

프로젝트의 Go 버전 기준은 루트의 [`go.mod`](../go.mod)를 따릅니다. 설치 방법은 [00장](00-setup/README.md), 집필 규칙은 [작성 지침](../docs/AUTHORING.md)을 참고합니다.
